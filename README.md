# Organizador de Escritorio Automático 🚀

Una herramienta sencilla escrita en Python para mantener tu escritorio limpio, clasificando archivos automáticamente según su extensión.

## ✨ Características
*   **Clasificación automática:** Mueve archivos a carpetas específicas (Documentos, Imágenes, Ejecutables, etc.).
*   **Extensible:** Fácil de configurar para añadir nuevos tipos de archivos.
*   **Ligero:** Ejecución rápida con mínimo consumo de recursos.

## 🛠️ Tecnologías
*   [Python 3.x](https://python.org)
*   Librerías estándar de Python (`os`, `shutil`, `pathlib`).

## 🚀 Instalación y Uso

1.  **Clona el repositorio:**
    ```bash
    git clone https://github.com
    cd organizador_escritorio
    ```

2.  **Configuración:**
    Edita el archivo `config.py` para definir tus rutas y extensiones personalizadas.

3.  **Ejecución:**
    ```bash
    python main.py
    ```

## 📂 Estructura del Proyecto
*   `main.py`: Punto de entrada de la aplicación.
*   `utils.py`: Funciones auxiliares de lógica de archivos.
*   `config.py`: Diccionarios de configuración y rutas.
